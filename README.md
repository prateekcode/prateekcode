## 🫧 Flagship: TidyDisk

<a href="https://github.com/prateekcode/tidydisk"><img src="https://raw.githubusercontent.com/prateekcode/tidydisk/main/web/screenshot.png" alt="TidyDisk main window" width="100%"></a>

**A native macOS app that clears the gigabytes developers lose to build caches.** TidyDisk finds Xcode DerivedData, `node_modules`, Gradle and package-manager caches. It only offers cleanups for tools you actually have installed, and sorts each one into a **safe**, **aggressive** or **nuclear** risk tier so nothing risky is ever pre-selected. It's written in Swift and SwiftUI, runs entirely on-device, and ships notarized for Apple Silicon and Intel.

[Source](https://github.com/prateekcode/tidydisk) &nbsp;·&nbsp; [Website](https://tidydisk.riekapps.com) &nbsp;·&nbsp; `brew install --cask prateekcode/tap/tidydisk`

## 🧭 How I work

- **Start from a real problem.** If I can't say who it's for, it doesn't get built.
- **Keep the architecture clear.** The next person to read the code should understand it.
- **Make trade-offs on purpose.** Every choice costs something, so I write down what we gave up.
- **Build for failure.** Networks drop, payments retry, disks fill up. The software should cope.
- **Ship, then measure.** Production teaches more than planning does.
